This is my android project for tracking vehicles and other objects of interests.
this app communicates with embedded system installed in the object of interest and communicates with the gps through sms 
This app  intends to offer features such as current vehicle tracking ,geofencing the object of interest ,saving coordinates for the object for future reference.
This app can also manage more than one  objects of interests ,thus we can be able to track more than one object under one user account.
This app can be used by more than user account.
